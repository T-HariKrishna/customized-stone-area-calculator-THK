# customized-stone-area-calculator-THK
A simple and fast stone calculation web application built using HTML, CSS, and JavaScript. This app helps calculate stone totals quickly using custom size and quantity inputs with automatic total calculation and dynamic row management.

# Stone Calculator

## Overview

* Simple stone calculation web application
* Built using HTML and basic JavaScript
* Designed for quick and easy calculations

## Features

* Simple and clean interface
* Multiple row calculations
* Automatic total calculation
* Easy data entry
* Fast calculation process

## Formula

* `(Size × Size) × Number of Stones`

## Technologies Used

* HTML
* CSS
* JavaScript


## Usage

* Enter stone sizes
* Enter number of stones
* Click calculate
* View total instantly
